## 📌 Project Description

**Campus Event & Student Club Hub** is a centralized platform designed for student organizations and university communities. The system enables clubs to:
- Publish and manage campus events and announcements.
- Handle student and member registrations seamlessly.
- Issue and validate digital tickets.
- Track real-time event attendance.
- Monitor and manage student club budgets and expenses.
